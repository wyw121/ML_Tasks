## ⚙️ 参数调整

编辑 `pm25_regression.py` 中的以下部分：

```python
# 在 main() 函数中修改
predictor = PM25Predictor(
    learning_rate=0.01,      # 学习率 (0.001~0.1)
    iterations=10000,        # 迭代次数 (1000~100000)
    epsilon=1e-8            # 平滑项
)
```

### 参数影响

| 调整 | 效果 |
|------|------|
| ↑ iterations | 训练更充分，但耗时增加 |
| ↓ iterations | 训练快速，但可能欠拟合 |
| ↑ learning_rate | 收敛速度快，但可能震荡 |
| ↓ learning_rate | 收敛稳定，但耗时增加 |

## ❓ 常见问题

### Q: 运行报错 "No module named 'numpy'"
**A**: 安装 NumPy
```bash
pip install numpy
```

### Q: 数据文件找不到
**A**: 确保文件路径正确
```
Expt1/
└── data/
    ├── train.csv    ✓
    └── test.csv     ✓
```

### Q: RMSE一直不下降
**A**: 检查
1. 数据是否正确加载
2. 学习率是否合适
3. 是否有缺失值处理问题

### Q: 预测结果全是相同的值
**A**: 可能的原因
1. 模型权重未更新（梯度计算错误）
2. 学习率过小
3. 数据预处理有问题

### Q: 输出出现 NaN 或 inf
**A**: 调整参数
```python
epsilon=1e-8      # 增加平滑项
learning_rate=0.01  # 适当降低学习率
```

## 📚 相关概念

### Adagrad算法要点

1. **自适应学习率** - 不同参数使用不同的学习率
2. **累积梯度** - 保留之前梯度的平方和
3. **参数更新** - $w = w - \frac{\alpha}{\sqrt{g + \epsilon}} \odot grad$

### PM2.5预测特点

- **多维输入** - 18种污染物，每种9小时数据
- **时间序列** - 前9小时预测第10小时
- **连续目标** - 预测的是连续的PM2.5值
