## 🔑 核心算法总结

### Adagrad（自适应梯度下降）

**问题**：标准梯度下降使用固定的学习率
```
w = w - α * ∇L(w)   // α是常数
```

**解决方案**：Adagrad自动调整每个参数的学习率
```
g ← g + (∇L)²        // 累积梯度平方
w ← w - α·∇L / √(g + ε)  // 参数独立的自适应学习率
```

**优势**：
- 无需手动调整学习率
- 适应数据的稀疏性
- 收敛速度快
- 每个参数独立优化

### 线性回归模型
```
ŷ = w₀ + w₁x₁ + ... + w₁₆₂x₁₆₂
或矩阵形式: ŷ = Xw
```

### 损失函数
```
MSE = (1/m) Σ(yᵢ - ŷᵢ)²
RMSE = √MSE
```
