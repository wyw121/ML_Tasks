## ⚙️ 参数调整

编辑 `logistic_regression.py` 中的模型创建部分：

```python
model = LogisticRegression(
    learning_rate=0.01,      # 学习率 (0.001~0.1)
    num_epoch=500,           # 训练轮数 (100~2000)
    batch_size=64,           # 批大小 (32~256)
    lambda_reg=0.0001,       # 正则化 (0~0.1)
    validation_split=0.1     # 验证比例 (0.1~0.3)
)
```

### 参数影响

| 调整 | 效果 |
|------|------|
| ↑ learning_rate | 收敛快，但可能不稳定 |
| ↓ learning_rate | 收敛稳定，但较慢 |
| ↑ num_epoch | 训练更充分，但耗时更长 |
| ↓ num_epoch | 训练快速，但可能欠拟合 |
| ↑ batch_size | 训练快，梯度稳定 |
| ↓ batch_size | 梯度更准确，但噪声大 |
| ↑ lambda_reg | 减少过拟合，但可能欠拟合 |
| ↑ validation_split | 更好的过拟合监控 |

## ❓ 常见问题

### Q: 找不到数据文件
**A**: 确保 `data/` 文件夹与 `logistic_regression.py` 在同一目录

### Q: ModuleNotFoundError: No module named 'numpy'
**A**: 安装 NumPy
```bash
pip install numpy matplotlib
```

### Q: 准确率很低 (<70%)
**A**: 
- 检查数据格式是否正确
- 尝试增加 num_epoch
- 调整 learning_rate

### Q: 程序运行很慢
**A**: 
- 增加 batch_size
- 减少 num_epoch
- 检查系统资源

### Q: 验证准确率下降（过拟合）
**A**: 
- 增加 lambda_reg
- 增加 validation_split
