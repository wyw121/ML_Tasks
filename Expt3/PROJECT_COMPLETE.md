## 💡 核心算法实现

### 1. Sigmoid激活函数
```python
def _sigmoid(self, z):
    """
    Sigmoid激活函数，数值稳定实现
    σ(z) = 1 / (1 + e^(-z))
    """
    # 避免溢出：使用np.clip限制输出范围
    return np.clip(1 / (1 + np.exp(-z)), 1e-6, 1 - 1e-6)
```

**特点**：
- ✅ 避免数值溢出
- ✅ 输出范围[0,1]表示概率
- ✅ 平滑的S形曲线

### 2. 交叉熵损失函数
```python
def _cross_entropy(self, y_true, y_pred):
    """
    二项交叉熵损失函数
    L = -[y·log(ŷ) + (1-y)·log(1-ŷ)]
    """
    m = len(y_true)
    loss = -np.mean(y_true * np.log(y_pred) + 
                    (1 - y_true) * np.log(1 - y_pred))
    return loss
```

**特点**：
- ✅ 衡量预测和真实标签差异
- ✅ 对分类错误的惩罚合理
- ✅ 数值稳定

### 3. 梯度计算
```python
def _gradient(self, X, y, y_pred):
    """
    梯度计算（使用微积分推导）
    ∇w L = -1/m X^T(ŷ - y) + λw
    ∇b L = -1/m Σ(ŷ - y)
    """
    m = len(y)
    error = y_pred - y
    w_grad = -1/m * (X.T @ error) + self.lambda_reg * self.w
    b_grad = -1/m * np.sum(error)
    return w_grad, b_grad
```

**特点**：
- ✅ 基于反向传播推导
- ✅ 包含L2正则化项
- ✅ 计算效率高

### 4. 小批量梯度下降
```python
def train(self):
    """
    小批量梯度下降训练
    - 每次使用batch_size个样本
    - 更新权重和偏置
    - 记录训练和验证指标
    """
    for epoch in range(self.num_epoch):
        # 随机划分小批量
        indices = np.random.permutation(m)
        for i in range(0, m, self.batch_size):
            # 计算梯度并更新
            w_grad, b_grad = self._gradient(X_batch, y_batch, y_pred)
            self.w -= self.learning_rate * w_grad
```

- ✅ 平衡收敛速度和稳定性
- ✅ 内存高效（64个样本/批）
- ✅ 有助于避免局部最优
