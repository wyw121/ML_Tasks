## 背景介绍

### 问题定义
给定一个人的特征（年龄、职业、教育等），预测其年收入是否超过50,000美元。

**问题类型**：二分类（Binary Classification）
**特征数**：106维（离散特征one-hot编码 + 连续特征）
**样本数**：训练32,561个，测试16,281个
**标签**：0（≤50K）或 1（>50K）

### 为什么不用线性回归？

线性回归的输出是连续的，无法直接用于分类。虽然可以设定阈值（如0.5），但存在以下问题：

1. **不符合概率理论**：线性回归的输出可能<0或>1
2. **边界不合理**：对极端值的惩罚不足
3. **假设不符**：误差不服从正态分布

## 线性回归 vs Logistic回归

### 线性回归
```
模型：ŷ = w·x + b
输出范围：(-∞, +∞)
用途：回归（连续值预测）
```

### Logistic回归
```
模型：ŷ = σ(w·x + b)，其中σ是sigmoid函数
输出范围：(0, 1)
用途：分类（概率预测）
解释：P(y=1|x)
```

## Logistic回归原理

### 1. Sigmoid函数

Sigmoid函数将任意输入映射到(0, 1)范围，代表概率：

$$\sigma(z) = \frac{1}{1 + e^{-z}}$$

**特性**：
- $\sigma(0) = 0.5$
- 当$z \to \infty$时，$\sigma(z) \to 1$
- 当$z \to -\infty$时，$\sigma(z) \to 0$
- 可微且光滑

**导数**：
$$\sigma'(z) = \sigma(z)(1 - \sigma(z))$$

### 2. 模型定义

$$h(x) = \sigma(w^Tx + b) = \frac{1}{1 + e^{-(w^Tx + b)}}$$

其中：
- $h(x)$ 表示$P(y=1|x)$的预测
- $w$ 是权重向量
- $b$ 是偏置项
- $x$ 是特征向量

### 3. 决策规则

预测标签：
$$\hat{y} = \begin{cases} 1 & \text{if } h(x) \geq 0.5 \\ 0 & \text{otherwise} \end{cases}$$

等价于：
$$\hat{y} = \begin{cases} 1 & \text{if } w^Tx + b \geq 0 \\ 0 & \text{otherwise} \end{cases}$$

## 二分类任务

### 概率理论

对于二分类问题，类条件概率为：
$$P(y=1|x) = h(x)$$
$$P(y=0|x) = 1 - h(x)$$

### 似然函数

对于单个样本：
$$P(y|x;w,b) = h(x)^y(1-h(x))^{1-y}$$

对于整个数据集：
$$L(w,b) = \prod_{i=1}^{m} h(x^{(i)})^{y^{(i)}}(1-h(x^{(i)}))^{1-y^{(i)}}$$

## 损失函数

### 交叉熵损失

对似然函数取对数（负数）得到损失函数：

$$L(w,b) = -\frac{1}{m}\sum_{i=1}^{m}[y^{(i)}\log(h(x^{(i)})) + (1-y^{(i)})\log(1-h(x^{(i)}))]$$

### 加上正则化

防止过拟合，添加L2正则化项：

$$L(w,b) = -\frac{1}{m}\sum_{i=1}^{m}[y^{(i)}\log(h(x^{(i)})) + (1-y^{(i)})\log(1-h(x^{(i)}))] + \frac{\lambda}{2m}||w||_2^2$$

其中：
- $\lambda$ 是正则化系数
- $||w||_2^2 = \sum_j w_j^2$

### 直观理解

对于二分类：
- 当$y=1$，$h(x) \to 1$时，损失 $\to 0$（正确预测）
- 当$y=1$，$h(x) \to 0$时，损失 $\to \infty$（错误预测）
- 当$y=0$，$h(x) \to 0$时，损失 $\to 0$（正确预测）
- 当$y=0$，$h(x) \to 1$时，损失 $\to \infty$（错误预测）

## 梯度下降

### 梯度推导

**对$w$的偏导**：

$$\frac{\partial L}{\partial w} = -\frac{1}{m}\sum_{i=1}^{m}(y^{(i)} - h(x^{(i)}))x^{(i)} + \frac{\lambda}{m}w$$

向量形式：
$$\frac{\partial L}{\partial w} = -\frac{1}{m}X^T(y - h(X)) + \frac{\lambda}{m}w$$

**对$b$的偏导**：

$$\frac{\partial L}{\partial b} = -\frac{1}{m}\sum_{i=1}^{m}(y^{(i)} - h(x^{(i)}))$$

### 参数更新

使用梯度下降：

$$w \leftarrow w - \alpha \frac{\partial L}{\partial w}$$

$$b \leftarrow b - \alpha \frac{\partial L}{\partial b}$$

其中$\alpha$是学习率。

### 批梯度下降 vs 随机梯度下降

**批梯度下降（BGD）**：
- 使用整个数据集计算梯度
- 每个epoch更新一次参数
- 收敛稳定，但慢

**小批量梯度下降（Mini-batch GD）**：
- 使用batch_size个样本计算梯度
- 平衡稳定性和速度
- 本实验使用这种方法

**随机梯度下降（SGD）**：
- 使用单个样本计算梯度
- 收敛快，但不稳定

## 数据处理

### 1. One-Hot编码

处理离散特征，例如性别：

```
原值：[male, female, male, female, ...]
编码：[1,0], [0,1], [1,0], [0,1], ...
```

优点：
- 适合机器学习算法
- 避免有序性假设

### 2. 正态标准化

处理连续特征：

$$x_{norm} = \frac{x - \mu}{\sigma}$$

其中：
- $\mu$ 是训练集的均值
- $\sigma$ 是训练集的标准差

**重要**：测试集使用训练集的$\mu$和$\sigma$

### 3. 特征缩放重要性

不缩放的问题：
- 不同尺度的特征权重初始化不同
- 梯度下降收敛速度不均
- 学习率选择困难

## 实现细节

### Sigmoid函数的数值稳定性

直接计算会导致溢出：
```python
z = w·x + b
if z > 700:  # exp(700)已经接近溢出
    exp(-z) 会为0，但浮点数溢出
```

解决方案：使用np.clip限制输出范围
```python
def sigmoid(z):
    return np.clip(1.0 / (1.0 + np.exp(-z)), 1e-6, 1 - 1e-6)
```

### 交叉熵的数值稳定性

直接计算log可能导致-inf：
```python
if y_pred == 0:
    log(y_pred) = -inf
```

解决方案：限制y_pred范围
```python
y_pred = np.clip(y_pred, 1e-6, 1 - 1e-6)
```

### 验证集的作用

使用验证集监控模型性能：
1. 检测过拟合：验证损失上升
2. 早停：当验证准确率不再提升时停止
3. 超参数选择：比较不同配置

### 批大小的影响

- batch_size = 1：SGD，梯度噪声大
- batch_size = m：BGD，计算消耗大但稳定
- batch_size = 32~256：Mini-batch，平衡

## 模型评估

### 准确率（Accuracy）

$$Accuracy = \frac{TP + TN}{TP + TN + FP + FN}$$

其中：
- TP：真正例（预测1，实际1）
- TN：真负例（预测0，实际0）
- FP：假正例（预测1，实际0）
- FN：假负例（预测0，实际1）

### 混淆矩阵

```
             预测0    预测1
实际0   TN(真负)   FP(假正)
实际1   FN(假负)   TP(真正)
```

### 精确率和召回率

**精确率**：
$$Precision = \frac{TP}{TP + FP}$$

**召回率**：
$$Recall = \frac{TP}{TP + FN}$$

### ROC-AUC曲线

绘制不同阈值下的TPR vs FPR，计算曲线下面积(AUC)。

## 特征重要性

### 基于权重的重要性

权重绝对值大的特征对预测影响大：

$$Importance_j = |w_j|$$

原因：
- 权重代表特征对输出的影响程度
- 绝对值越大，特征越重要

### 应用场景

1. **特征选择**：删除不重要特征
2. **特征解释**：理解模型决策
3. **业务洞察**：找出关键影响因素

## 完整流程图

```
加载数据
   ↓
数据预处理（标准化、one-hot编码）
   ↓
分割训练/验证集
   ↓
初始化w=0, b=0
   ↓
for epoch in range(num_epoch):
   ↓
   for batch in data:
      ↓
      计算预测: h = sigmoid(w·X + b)
      ↓
      计算梯度: ∇w, ∇b
      ↓
      更新参数: w -= α·∇w, b -= α·∇b
   ↓
   计算训练/验证损失和准确率
   ↓
保存最优模型
   ↓
对测试集预测
   ↓
输出结果
```

## 常见问题

### Q: 为什么使用交叉熵而不是MSE？

A: 
- 交叉熵：梯度与y_pred-y_true成正比，梯度信号清晰
- MSE：梯度与σ'(z)相乘，学习率不稳定
- 交叉熵更适合分类问题

### Q: 特征标准化必要吗？

A:
- 不是必需，但强烈推荐
- 加快收敛速度（10~100倍）
- 避免学习率难以选择

### Q: 什么时候停止训练？

A:
- 验证准确率不再提升
- 验证损失开始上升
- 达到设定的epoch数
