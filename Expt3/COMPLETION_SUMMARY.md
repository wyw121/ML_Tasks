## 🔑 算法实现特点

### Sigmoid函数
```python
σ(z) = 1 / (1 + e^(-z))
使用np.clip(σ, 1e-6, 1-1e-6)避免数值溢出
```

### 损失函数（交叉熵）
```
L = -1/m Σ[y·log(ŷ) + (1-y)·log(1-ŷ)] + λ||w||²
其中ŷ = σ(w·x + b)
```

### 梯度更新
```
w_grad = -1/m X^T(ŷ - y) + λw
b_grad = -1/m Σ(ŷ - y)
w ← w - α·w_grad
b ← b - α·b_grad
```

### 批梯度下降
- 使用batch_size（默认64）个样本计算梯度
- 平衡收敛稳定性和计算效率
- 记录训练/验证损失和准确率

### 默认参数
```python

batch_size=64          # 批大小
```

### 调参建议

**如果过拟合**：
- ↑ lambda_reg（增加正则化）
- ↑ validation_split（更多验证样本）
- ↓ num_epoch（减少训练轮数）

**如果欠拟合**：
- ↓ lambda_reg（减少正则化）
- ↑ num_epoch（增加训练轮数）
- ↑ learning_rate（加快收敛）

**如果收敛慢**：
- ↑ batch_size（更大批次）
- ↑ learning_rate（更大学习率）

## 🔍 核心方程总结

### Sigmoid函数
$$\sigma(z) = \frac{1}{1 + e^{-z}}$$

### 交叉熵损失
$$L = -\frac{1}{m}\sum[y\log(\hat{y}) + (1-y)\log(1-\hat{y})] + \lambda||w||^2$$

### 权重梯度
$$\nabla_w L = -\frac{1}{m}X^T(\hat{y} - y) + \lambda w$$

### 偏置梯度
$$\nabla_b L = -\frac{1}{m}\sum(\hat{y} - y)$$

### 参数更新
$$w \leftarrow w - \alpha \nabla_w L$$
$$b \leftarrow b - \alpha \nabla_b L$$
