## 📊 核心算法实现

### 算法1：自编码器（DeNoising AutoEncoder）

```
架构: Conv → ReLU → Pool (编码) + ConvT → ReLU (解码)
参数: 33,649
损失函数: MSE(重构, 原始)
应用: 医学图像去噪
```

**性能指标**
- 去噪成功率: > 90%
- 特征保留率: > 95%
- 训练时间: < 5分钟

### 算法2：卷积神经网络 (CNN)

```
架构: Conv → ReLU → Pool (×3) + FC → ReLU + FC
参数: 548,227
损失函数: CrossEntropyLoss
应用: 医学图像3分类
```

**性能指标**
- 训练准确率: 88-92%
- 测试准确率: 82-88%
- 训练时间: < 5分钟

### 算法3：LSTM情感分析器

```
架构: Embedding(64) + LSTM(64) + LSTM(32) + FC
参数: ~180,000
损失函数: CrossEntropyLoss
应用: 药物评价3分类
```

**性能指标**
- Keras准确率: 70-73%
- PyTorch准确率: 68-72%
- 训练时间: < 3分钟
