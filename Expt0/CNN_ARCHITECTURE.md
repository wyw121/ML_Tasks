# CNN网络结构详解

## 网络架构图

```
输入图像
64 × 64 × 1
      ↓
[卷积层1] Conv2d(1→16, 3×3, padding=1)
16 × 64 × 64
      ↓
[激活函数] ReLU
16 × 64 × 64
      ↓
[池化层1] MaxPool2d(2×2, stride=2)
16 × 32 × 32
      ↓
[卷积层2] Conv2d(16→32, 3×3, padding=1)
32 × 32 × 32
      ↓
[激活函数] ReLU
32 × 32 × 32
      ↓
[池化层2] MaxPool2d(2×2, stride=2)
32 × 16 × 16
      ↓
[卷积层3] Conv2d(32→64, 3×3, padding=1)
64 × 16 × 16
      ↓
[激活函数] ReLU
64 × 16 × 16
      ↓
[池化层3] MaxPool2d(2×2, stride=2)
64 × 8 × 8
      ↓
[展平层] Flatten
4096 (64×8×8)
      ↓
[全连接层1] Linear(4096→128)
128
      ↓
[激活函数] ReLU
128
      ↓
[Dropout] p=0.5
128
      ↓
[全连接层2] Linear(128→3)
3
      ↓
[输出层] Softmax
3（类别概率）
```

## 详细计算过程

### 卷积层计算公式

```
输出大小 = (输入大小 - 卷积核大小 + 2×padding) / stride + 1

参数数量 = (卷积核高 × 卷积核宽 × 输入通道 + 1) × 输出通道
         = (3 × 3 × input_channels + 1) × output_channels
```

### 各层详解

#### 第一个卷积块
```
卷积层1: Conv2d(1, 16, kernel_size=3, stride=1, padding=1)
输出大小计算: (64 - 3 + 2×1) / 1 + 1 = 64
参数数量: (3×3×1 + 1) × 16 = 160

激活函数: ReLU(x) = max(0, x)
作用: 增加非线性，提高表达能力

池化层1: MaxPool2d(2, 2)
输出大小计算: (64 - 2) / 2 + 1 = 32
参数数量: 0（无参数）
```

#### 第二个卷积块
```
卷积层2: Conv2d(16, 32, kernel_size=3, stride=1, padding=1)
输出大小计算: (32 - 3 + 2×1) / 1 + 1 = 32
参数数量: (3×3×16 + 1) × 32 = 4,640

池化层2: MaxPool2d(2, 2)
输出大小计算: (32 - 2) / 2 + 1 = 16
参数数量: 0
```

#### 第三个卷积块
```
卷积层3: Conv2d(32, 64, kernel_size=3, stride=1, padding=1)
输出大小计算: (16 - 3 + 2×1) / 1 + 1 = 16
参数数量: (3×3×32 + 1) × 64 = 18,496

池化层3: MaxPool2d(2, 2)
输出大小计算: (16 - 2) / 2 + 1 = 8
参数数量: 0
```

#### 全连接层
```
展平: 64 × 8 × 8 = 4096

全连接层1: Linear(4096, 128)
参数数量: (4096 + 1) × 128 = 524,544

Dropout: 随机丢弃50%的神经元
作用: 防止过拟合

全连接层2: Linear(128, 3)
参数数量: (128 + 1) × 3 = 387

输出层: Softmax
作用: 将3个输出转换为概率分布
```

## 信息流动演示

以一个样本为例展示数据流动：

```
输入: (1, 64, 64) - 一张灰度图

Conv1(1→16): 
  16个3×3卷积核扫描图像
  提取16种基础特征（如边缘、纹理）
  输出: (16, 64, 64)

Pool1:
  16个32×32的特征图
  保留最显著的特征
  输出: (16, 32, 32)

Conv2(16→32):
  32个3×3卷积核
  组合第一层的16个特征
  提取32种中级特征（如角、形状）
  输出: (32, 32, 32)

Pool2:
  32个16×16的特征图
  输出: (32, 16, 16)

Conv3(32→64):
  64个3×3卷积核
  组合第二层的32个特征
  提取64种高级特征（如器官部分）
  输出: (64, 16, 16)

Pool3:
  64个8×8的特征图
  输出: (64, 8, 8)

Flatten:
  将4096个元素展平为一维向量
  输出: (4096,)

FC1(4096→128):
  降维，融合所有特征
  学习分类相关的特征组合
  输出: (128,)

ReLU + Dropout:
  激活非线性
  随机丢弃50%的神经元防止过拟合
  输出: (128,)

FC2(128→3):
  最终分类层
  输出3个类别的logits
  输出: (3,)

Softmax:
  转换为概率分布
  输出: (3,) - 每个类别的概率
```

## 特征提取过程

### 第1层特征（基础特征）
- 简单边缘检测
- 颜色/灰度变化
- 基本纹理

**示例**：识别X光片中的边界

### 第2层特征（中级特征）
- 角、曲线、形状
- 医学上的区域特征
- 组织密度变化

**示例**：识别肺部的具体形状

### 第3层特征（高级特征）
- 器官部分
- 病变模式
- 疾病特异性特征

**示例**：识别COVID肺炎的特征病灶

## 计算复杂度分析

### 时间复杂度
```
卷积运算: O(H × W × K × K × C_in × C_out)
其中:
  H, W: 输入高度和宽度
  K: 卷积核大小
  C_in: 输入通道数
  C_out: 输出通道数

全连接层: O(N × M)
其中:
  N: 输入维度
  M: 输出维度
```

### 空间复杂度
```
模型参数总数: 约548K参数
激活值存储: 训练时需要存储中间结果
单样本推理: 内存占用约5-10MB
```

```python

```


### 4. 不同激活函数
```python

```
